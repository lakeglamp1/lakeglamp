# LakeGlamp

Адаптивный лендинг на HTML, CSS и JavaScript без внешних зависимостей.

Запуск: `npm run dev`, затем открыть http://127.0.0.1:4173.

Публикуемая папка: `dist/`. Галерея, просмотр домиков, фильтры и подготовка запроса дат работают в браузере. Запрос открывает на выбор WhatsApp +7 993 094-85-92 или Telegram @alinatur30; подтверждение и оплату согласует администратор. В запрос можно добавить отдельно баню на дровах и банный чан.

Переключатель светлой темы и темы хаки расположен в шапке. Выбор хранится в `localStorage` под ключом `lakeglamp-theme`; до первого выбора учитывается тема устройства. Если хранилище недоступно, переключение работает на текущей странице.
